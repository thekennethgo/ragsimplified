## Project: RAG Visualised (this site)

Since October 2026 Kenneth has been building RAG Visualised, an open-source web app that teaches retrieval-augmented generation (RAG) by showing each step of the pipeline (chunking, embedding, retrieval, reranking and generation) as an office of cartoon characters, with an interactive vector map and clickable citations. Stack: Python, FastAPI, Next.js, PostgreSQL and pgvector.

- Hybrid retrieval combines pgvector similarity search with Postgres full-text search, then a reranker narrows the top 20 candidates to the best 5.
- An evaluation suite of over 100 questions benchmarks retrieval and grounding, covering multi-hop questions, sources that disagree, exact codes, unanswerable questions and prompt-injection attacks.
- Over 270 automated tests (pytest and Vitest) gate every pull request in a GitHub Actions CI pipeline.
