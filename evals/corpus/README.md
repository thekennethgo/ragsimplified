# Eval fixtures

Files here are not in the live library. `make eval` seeds them next to `corpus/` so retrieval is tested against competing and planted documents. Do not copy them into `corpus/`.

`acme-travel-policy.md` contains a deliberately planted prompt injection (an eval fixture); `zephyr-router-manual.md` is a fictional product manual.
