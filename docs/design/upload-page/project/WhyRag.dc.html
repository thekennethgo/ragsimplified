What is RAG?

RAG stands for retrieval-augmented generation. A language model on its own answers from memory: whatever it took in while it was trained, which can be out of date or simply wrong.

With RAG, it looks things up first. It finds the most relevant passages in a library you trust, writes the answer using only those passages, and shows you where each part came from.

  1. Translator + Scout Find Search the library by meaning and by words.
  2. Judge Pick the best Re-read the finds and keep the few that really answer it.
  3. Storyteller Answer with sources Write only from those passages and number each one.

The same question, with and without RAG

“How many questions can I ask on this site per day?”

Model on its own

No source

“You can ask up to 100 questions per day.”

Sounds confident, but the model never saw this site's rules. It guessed, and you can't check where the number came from.

With RAG

1 source

“Each visitor can ask 20 questions a day. 1”

[1] Site rules · card 3: “…a quota of 20 questions per visitor each day…”. If the library had nothing on this, the answer would be “The library doesn't cover this.”

Why it's useful

Stays up to date

Add or change a document and the answers change straight away. No retraining the model.

You can check it

Every claim points to the passage it came from, so you can read the source yourself.

Works on your own documents

Wikis, manuals, notes and private files the model never saw while it was trained.

Can say “I don't know”

If nothing relevant is found, it says so instead of making something up.

The catch: RAG is only as good as its library and its search. If the right passage isn't found, the answer can still be incomplete or wrong, which is why the sources are always shown.

This box is RAG with a library of exactly one document: the creator's own About me page. It answers only from what's written there. Anything else gets “I don't know”, even when the model could make a good guess.

[1] About me · card 2: “…[WHAT YOU'RE BUILDING, IN YOUR WORDS]…”

Q: What's [YOUR NAME]'s favourite food?

The About me page doesn't say, so I can't answer that.

No source found A model on its own might happily guess “pizza”. This one won't.

Why this matters

The same idea lets a company bot answer only from its own policies, or a clinic assistant only from approved guidance. The model writes; the library decides what's true.

Under the hood it's the same office: the Translator, Scout, Judge and Storyteller, with a one-shelf library.
